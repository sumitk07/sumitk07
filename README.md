### Research prototypes

| Project | Question | First result |
|---|---|---|
| [**crosslingual-search-ja**](https://github.com/sumitk07/crosslingual-search-ja) | How much does search get worse when a Japanese question is asked in English or Hindi instead? | On 100 MIRACL-ja questions, multilingual-E5 dropped from 0.818 nDCG@10 (Japanese) to 0.680 (English) and 0.644 (Hindi). Simple rank fusion with BM25 did not help. |
| [**fedroutine**](https://github.com/sumitk07/fedroutine) | Can personalised federated learning learn each older person's daily routine from home sensors, without raw data leaving the home? | On 10 simulated homes, personalised FL (FedPer) matched central training (AUROC 0.844 vs 0.839). Standard FedAvg failed for a late sleeper (0.50); FedPer fixed it (0.84). |

Both repositories include the code, how to run it, the full results, and an honest list of limitations and next steps.
